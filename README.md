# 藏宝阁

个人收藏与文档管理 PWA — 实物资产 + 知识资产双引擎。

## 功能

- 📦 **藏品阁**：手办/积木/模型/书/周边/纪念品/玩具记录，支持多图、价格、位置、标签
- 📝 **文渊阁**：Markdown 文档编辑，支持复盘/写作/随笔/技术笔记等分类，自动字数统计
- 🔍 **全局搜索**：跨藏品和文档全文检索
- 💾 **一键导出/导入**：JSON 备份，数据永不丢失
- 📱 **PWA**：添加到手机主屏幕，离线可用

## 技术栈

纯静态 HTML/CSS/JS，IndexedDB 本地存储，零依赖，零后端。

## 部署到 GitHub Pages

1. Fork 本仓库
2. Settings → Pages → Source: `main` → Save
3. 等 1 分钟，访问 `https://你的用户名.github.io/treasure-nest`
